# Kala Agni – Cinematic 3D Space Situational Awareness Visualizer

Hey there! 

**Kala Agni** is my high-fidelity 3D orbital visualization tool — built as a companion to my main project **Sudarshan SSA Dashboard**.

I created it because I wanted a beautiful, smooth, and physically accurate way to explore orbits, satellites, and space situational awareness scenarios. It’s cinematic, responsive, and feels like something you’d actually use in a real mission control environment.

### What it does
- Real-time 3D Earth with live orbital propagation (SGP4)
- Clean visualization of multiple satellites and their trajectories
- Telemetry overlays (temperature, voltage, attitude, etc.)
- Interactive controls for exploring different orbital scenarios
- Designed to work together with Sudarshan for physics-guided research

### Why I built it
After my internship at ISRO VSSC working on telemetry anomaly detection, I wanted tools that not only analyze data but also help you *see* and *feel* what’s happening in orbit. Kala Agni is that visual layer.

It’s also directly connected to the research I recently submitted:
→ **Physics-Guided Synthetic Telemetry Generation for Robust Spacecraft Anomaly Detection** (engrXiv, April 2026)

### Tech Stack
- Python + Streamlit
- Three.js for smooth 3D rendering
- SGP4 / Poliastro for orbital mechanics
- Physics-informed models from my anomaly detection work
